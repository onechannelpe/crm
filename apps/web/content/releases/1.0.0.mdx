# Lanzamiento del sistema

El sistema de gestión está disponible para todo el equipo. Esta primera versión incluye los módulos principales para gestionar contactos, inventario, agenda y actividad comercial.

## Módulos disponibles

- **Dashboard** — visión general de actividad y métricas del equipo
- **Contactos** — gestión de clientes, proveedores y personas
- **Inventario** — seguimiento de productos, stock y precios
- **Agenda** — calendario de actividades, llamadas y reuniones
- **Ventas** — registro de oportunidades y seguimiento comercial

## Acceso

El acceso está restringido a usuarios autorizados por la organización. Contacta al administrador para obtener tus credenciales.
